## Why

现有原生适配器重复构造Apple Events、文件持久化重复设置私有权限，工具定义在发现/授权/路由时反复重建。精简这些等价实现，同时保留所有当前功能、接口和安全边界。

## What Changes

- 合并无业务状态的Apple Events描述符构造及后台应用查找/权限探针；应用授权与错误映射仍由原适配器负责。
- 合并完全等价的原子JSON写入与0600权限设置。
- 缓存静态工具定义，简化重复路由/编码中确有等价替换的部分。
- 用既有测试及必要的针对性回归核对权限、路径边界、取消、操作唯一性、内容分页和错误语义。

## Impact

仅精简当前代码，不扩展功能、不新增依赖、不改Apple数据，不发邮件/短信、不录音、不打开分屏。没有新增Hash、冻结接口、Baseline或Gate。签名构建只用于验证源码可构建，不默认重启当前服务。
