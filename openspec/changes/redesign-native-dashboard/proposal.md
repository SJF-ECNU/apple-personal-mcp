## Why

现有 App 将 Agent 管理与系统授权分为两个表单窗口，缺少清晰的能力状态、接入步骤和调用结果。用户确定优先完善原生 UI，采用黑灰深色界面与六个系统应用的本机原生图标。

## What Changes

- 一个可调整大小的主窗口，提供概览、Agent、应用、活动四个页面。
- 黑灰层次、米白文字与主按钮；应用图标保留原色，不以绿色作为主色。
- 复用注册表与已有授权动作，展示实际检查结果、最近检查时间和内容无关的调用记录。
- 完成本机签名安装与界面验证，保留权限、撤销、XPC 和本机确认行为。

## Capabilities

### New Capabilities
- `native-dashboard`: 原生深色管理界面。

## Impact

修改 NativeHost 的界面组织，不增加 MCP 管理权限、后台轮询或新邮件触发。系统授权仍须用户在 macOS 中完成；活动不展示邮件、笔记、聊天或转写正文。
