## ADDED Requirements

### Requirement: 统一原生深色窗口
App SHALL 在单个可调整窗口内提供概览、Agent、应用和活动页面，使用黑灰主色和米白强调色，六应用使用本机应用图标并保留原色。

#### Scenario: 多次打开 App
- **WHEN** 用户从菜单或应用入口打开管理界面
- **THEN** 聚焦已有主窗口并进入相应页面，不重复创建设置窗口

### Requirement: 保持授权与管理语义
界面 SHALL 复用现有 Agent 注册表及系统授权动作，默认不勾选权限，显示权限依赖，不暴露密钥；撤销和其他既有危险操作 SHALL 保留本机确认。

#### Scenario: 编辑并撤销临时 Agent
- **WHEN** 用户创建、修改权限、复制配置并确认撤销临时 Agent
- **THEN** 注册表结果与操作一致，原有 Agent 不变，旧凭据失效，配置不含密钥

#### Scenario: 存在未保存修改
- **WHEN** 用户编辑后选择另一个 Agent 或新建项
- **THEN** 界面要求确认放弃修改或继续编辑，不静默覆盖

### Requirement: 真实且有界的状态展示
App SHALL 标明状态来源与检查时间，将系统访问状态与 Agent 权限区分；状态检查不阻塞主线程，不新增周期轮询，不在查看页面时自动发起系统授权。

#### Scenario: 未授权或检查失败
- **WHEN** 应用访问不可用
- **THEN** 显示具体状态与相应设置入口，不显示 ready 或原始 JSON，不猜测未检查的数据

### Requirement: 内容无关活动
App SHALL 从现有活动日志有界读取最近请求，仅显示工具、Agent、阶段、时间与耗时，不展示工具参数、正文或凭据。

#### Scenario: 空日志或末尾半行
- **WHEN** 日志为空、缺失或最后一行尚未写完
- **THEN** 界面正常显示空状态或其余完整记录，不无限读取或阻塞
