## 界面与数据

窗口使用 SwiftUI 内容与 AppKit 生命周期，保留已有菜单栏宿主和 owner XPC。正常打开 App 聚焦唯一主窗口；菜单入口进入对应页面，不创建第二个设置窗口。

背景 #141416，侧栏 #1C1C1E，面板 #232326，选中 #303034，主文字 #F5F5F7，次文字 #A1A1A6。主按钮米白底黑字；危险动作使用语义色与已有确认。图标通过 NSWorkspace 定位本机应用并读取，不复制 Apple 图标进仓库。无应用时显示系统符号并标注状态。

- 概览：服务注册状态、有效 Agent 数、六应用检查结果与接入步骤。注册状态不能冒充真实连接或在线数量；不显示虚构统计。
- Agent：独立列表与权限编辑，默认空授权，保存时沿用 read/write/send 依赖；复制配置不显示密钥，撤销仍需本机确认。存在未保存修改时切换选择或关闭窗口应确认；已撤销记录默认隐藏，可显式显示。
- 应用：区分系统访问检查与 Agent 授权；复用 FDA 设置、EventKit、各应用自动化及录音快捷指令设置入口。不在打开页面时自动请求权限。
- 活动：只从现有 activity.jsonl 尾部有界读取，按请求合并最近状态；仅展示已知字段，不读取通信正文。没有记录时显示空状态。

状态检查放后台且同一时刻最多一轮；仅显示窗口和用户点击刷新时执行，不新增周期计时器。Notes/EventKit 为授权检查，不能冒充内容读取验证。Mail/Messages/Voice 的本地检查明确实际来源；失败展示可行动说明，不渲染原始 JSON。

## 实施与验证

替换现有管理表单，保留 AgentAdministration 命令行入口和核心服务代码。沿用现有 AppDelegate 授权方法，通过界面动作回调复用。验证完整测试、签名构建及本机可调整窗口、四页导航、创建/复制/编辑/撤销临时无权限 Agent。UI 验证不外发、不修改六应用数据，不开分屏；原有 Claude Code Agent 保留。
