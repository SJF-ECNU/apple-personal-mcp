# 原生深色管理界面验证

2026-10-27，macOS 27 arm64，Development 签名的 ApplePersonalMCP.app。本轮修改 NativeHost 界面，沿用现有 PersonalCore、stdio 桥接、权限、XPC 和本机确认实现；不新增运行时依赖。

## 已实际验证

- 统一窗口包含概览、Agent、应用、活动；黑灰背景、米白强调色，六个应用图标通过 NSWorkspace 从本机应用读取并保留原色。
- 默认 1120×790 窗口与原生「窗口→缩放」后布局可用，已恢复默认尺寸；没有打开分屏或全屏空间。反复唤起保留当前页面，避免焦点切换时重置导航与重复检查。
- 状态在后台单次检查，当前六应用均显示可用。Mail/Messages/Voice 为本地数据访问检查，Notes/EventKit 为授权检查，界面明确区分，不代表逐项内容或云端同步全部验收。
- 从真实界面创建一名零应用权限的临时 Agent，14 个权限勾选框默认全关。勾选 Mail 发送时读取/修改自动开启；取消读取时三个权限一起取消。依赖联动仅在未保存表单中测试，没有将这些读取/发送权限授予临时 Agent。
- 切换 Agent 时的未保存提醒、继续编辑、配置复制反馈、原生撤销确认和撤销后禁用控件均通过。关闭按钮与 ⌘W 均会提示未保存修改，确认放弃后重新打开字段为空。
- 临时 Agent 通过真实 stdio 入口调用 doctor，六应用均返回 permission_denied。随后经界面确认撤销，凭据文件删除；原有全部 Agent 的名称、权限集合、撤销状态保持不变。
- 已撤销记录默认隐藏，可显式显示。活动列表将同一请求合并为最近状态，实际显示真实工具调用、阶段、时间与毫秒耗时；读取上限 256 KiB、展示上限 80 个请求，不显示参数、正文和凭据。
- 标准菜单提供 ⌘W 关闭、⌘R 刷新及复制/粘贴等编辑入口，保持原有菜单栏入口与用户服务。
