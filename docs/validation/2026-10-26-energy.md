# Instruments 轻量读取采样

2026-10-26，Development 签名的 0.4.0 原生 App，macOS 27.0 arm64；GUI Instruments 27.1（27A9275）。用户通过已配置的 Claude Code MCP 执行读取，采样 61.144 秒；活动记录对应一次 mail_overview、两次 mail_search，均完成。这里只分析 ApplePersonalMCPHost，不包含 CLI 桥接或其他系统应用的成本。

| 指标 | 本轮观察 |
| --- | --- |
| CPU 时间加权平均 / 采样峰值 | 2.31% / 4.19%，单核满载为 100% |
| CPU 累计计数器在区间内的增量 | 1.386 秒 |
| 内存 footprint 首 / 尾 / 峰值 | 14.50 / 14.78 / 15.56 MiB |
| Idle wakeups 增量 | 438，约 7.16 次/秒 |
| 磁盘读 / 写计数器增量 | 1,982,464 / 147,456 字节 |
| 线程数 | 3–5 |
| Preventing sleep | 未观察到 |
| Thermal state | 全程 Nominal |
| 三次读取的宿主执行时间合计 | 约 23.37 毫秒 |

Time Profiler 采到约 1.319 秒 CPU，主线程约占 80.6%，主要路径是 AppKit 事件循环与窗口维护。包含调用栈的百分比会重叠，不能相加，也不能据此把全部窗口维护归因给 MCP 查询。本轮负载较轻，未观察到明显的业务热点；样本不足以支持进一步修改业务代码。

本机 Power Profiler 探测报告该目标平台不受支持；实际使用 Activity Monitor 和 Time Profiler。本轮没有测得进程瓦特、掉电速度或续航。没有完成独立空闲、多 Agent 并发或长音频转写的分组采集，也不是受控的优化前后比较。唤醒和 IO 均使用区间首尾计数差，不能使用进程生命周期累计值冒充本轮消耗。

原始 trace、XML 导出及本机诊断文件保留在忽略的本地目录；本摘要不含正文、地址、录音、凭据、进程 ID 或设备标识。
