# v0.5.0 · 原生深色界面与 App 图标

Apple Personal MCP 首个公开开发预览 Release，面向 Apple silicon、macOS 26 及以上。

## 本次更新

- 统一的原生黑灰管理窗口：概览、Agent、应用、活动四个页面。
- 简约黑白「入口与工作空间」App 图标，接入应用保留各自的原生图标。
- 独立 Agent 权限、权限勾选联动、配置复制、未保存修改提醒和撤销确认。
- 后台单次状态检查与有界活动列表；活动不显示参数、正文或凭据。
- 优化构建脚本支持 `--release`，应用内附 MIT 与第三方许可文件。

六应用现有能力包含 Mail 邮件与草稿、Calendar/Reminders 读写、Notes 普通正文与附件、Messages 本机历史与确认发送、Voice Memos 原始录音/转写及本地语音任务。发送、删除与录音控制沿用本机确认；具体能力和覆盖范围见 README 与验证记录。

## 下载与使用

资产 `ApplePersonalMCP-v0.5.0-macos-arm64.zip` 包含优化构建的 App。解压后将 `ApplePersonalMCP.app` 放入 `/Applications`，首次使用仍需完成 macOS 系统授权、启用用户服务并为客户端创建独立 Agent。

**签名状态：Apple Development，未公证。** 当前没有 Developer ID 发行证书，其他 Mac 的系统分发校验可能拒绝直接运行。可以从此标签源码使用本机有效签名身份构建：

```sh
Scripts/build-app.sh --release --install
/Applications/ApplePersonalMCP.app/Contents/MacOS/ApplePersonalMCPHost --register
```

完整的系统授权与 MCP 配置步骤见 [README](https://github.com/SJF-ECNU/apple-personal-mcp/blob/v0.5.0/README.md)。每个使用者都需创建自己的 Agent 凭据；分发包不包含开发者的任何运行数据或凭据。

原生界面、窗口缩放、未保存修改确认及零应用权限临时 Agent 的创建/复制/撤销已在本机验证；已有客户端六应用状态检查通过。历史的实发、录音与其他数据操作证据分别保留在验证文档中，本轮没有重新外发或录音。优化构建、测试、签名与资产检查见 [本次发行记录](https://github.com/SJF-ECNU/apple-personal-mcp/blob/v0.5.0/docs/validation/2026-10-27-release.md)。
